# Community Health Clinic

## Project Overview

The Community Health Clinic is a Flutter-based mobile application developed to provide a simple and user-friendly platform for a community health clinic.

The application serves as a starting point for developing a digital healthcare management system that can help improve communication and access to basic clinic services.

## Project Objectives

- Develop a simple and attractive healthcare application.
- Provide a welcoming interface for clinic users.
- Practise Flutter and Dart programming.
- Build a foundation for future healthcare management features.

## Technologies Used

- **Flutter:** Mobile application development framework.
- **Dart:** Programming language.
- **Visual Studio Code:** Development environment.
- **Material Design:** User interface components.

## Application Features

- Welcome screen.
- Application title and navigation bar.
- Clean and simple user interface.
- Responsive Flutter layout.

## Installation and Setup

### 1. Install Flutter

Download and install Flutter SDK from:

https://flutter.dev

### 2. Clone or Open the Project

Open the project folder in Visual Studio Code.

### 3. Install Dependencies

Run the following command in the terminal:

```bash
flutter pub get
```

### 4. Run the Application

Execute:

```bash
flutter run
```

## How the Application Works

When the application starts, Flutter executes the `main()` function, which launches the `CommunityHealthClinic` widget.

The application displays a home page containing:
- An AppBar with the title Community Health Clinic.
- A blue application header.
- A welcome message displayed at the centre of the screen.
